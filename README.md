# 📚 History Study - 高考历史备考学习环境

面向 **2027年安徽高考历史** 的引导式学习仓库。

## 🎯 项目目标

通过与 GitHub Copilot 的互动式学习，系统掌握高中历史必修和选修课程，备战2027年高考。

## 📖 学习方法

本项目采用**引导式学习**方法：
- 🤔 苏格拉底式提问，引导主动思考
- 📝 每个知识点充分练习（5-8道题目）
- ❌ 错题引导式纠正，不直接给答案
- 🔄 艾宾浩斯复习计划，科学记忆
- 📊 进度追踪，实时掌握学习情况

## 🚀 如何使用

1. 打开 VS Code，确保已安装 GitHub Copilot
2. 在 Copilot Chat 中开始学习对话
3. 告诉 Copilot 你想学习哪个知识点，或者让它出题
4. 学习结束后，Copilot 会自动更新进度追踪

## 📅 学习规则

- 每次学习至少 **30分钟**
- 每个知识点至少练习 **5-8道题**
- 错题必须**引导式纠正** + **复述确认**
- 按照**艾宾浩斯曲线**复习（1-2-4-7-15-30天）

## 🔥 高频考点

### 中国古代史
- 秦汉大一统国家治理
- 唐宋变革与社会转型
- 明清时期的政治与文化

### 中国近现代史
- 晚清社会变革与救亡图存
- 新民主主义革命
- 社会主义建设与改革开放

### 世界史
- 工业革命与资本主义发展
- 两次世界大战
- 冷战与两极格局
